# Qraft

Qraft is a PHP package for QR code generation, created for use in my project.

## About

I needed QR code generation in my project, but I didn't yet understand how QR
codes work. I started Qraft to learn the concepts behind QR codes while
building a package I could use in my project. and also learn on how to build a php package, maybe someday i will add it as a laravel package 

## Goals

- Learn how QR codes are structured and generated.
- Build QR code generation in PHP.
- Use the package to generate QR codes for my project.

## Project status

This project is a learning project and is being developed. Installation and
usage instructions will be added when the package's setup and API are ready.
